# Expense Tracker Frontend (React)

A lightweight React UI for managing personal expenses: add, edit, delete expenses and categories, filter and list expenses, visualize monthly totals, and export CSV.

## Features

- Expenses
  - Add, edit, delete
  - Filter by date range and category
  - Table view with totals
  - CSV export using backend `/export/`
- Categories
  - Add, rename, delete
- Charts
  - SVG stacked bar chart of monthly totals by category
- UX
  - Loading and error states
  - Light/Dark theme toggle

## Getting Started

1) Install dependencies:
   npm install

2) Configure backend API URL:
   Create a .env file in this folder with:
   REACT_APP_API_BASE_URL=http://localhost:5000

   Notes:
   - Do not commit secrets. The orchestrator will set environment variables in CI.
   - If REACT_APP_API_BASE_URL is not provided, the app will call "/api" relative path; ensure a proxy is set up externally.

3) Run the app:
   npm start

   The app will open at http://localhost:3000

4) Build for production:
   npm run build
   Notes:
   - CI builds use BROWSERSLIST_IGNORE_OLD_DATA=1 to suppress update prompts.
   - For local dev, you can optionally run: npx update-browserslist-db@latest

5) Run tests:
   npm test

## Backend API

This frontend expects the backend routes (from the OpenAPI spec):
- GET/POST /categories/
- PUT/DELETE /categories/{id}
- GET/POST /expenses/
- PUT/DELETE /expenses/{id}
- GET /export/ (returns CSV)

Ensure the backend is running and accessible at REACT_APP_API_BASE_URL.

## CSV Export

The "Export CSV" button downloads a CSV generated by the backend applying the current filters (date range and category).

## Theming

Use the header theme toggle to switch between Light and Dark. Theme is applied via data-theme attribute and CSS variables in src/App.css.

## Project Structure

- src/services/api.js — API client
- src/hooks/* — data hooks for expenses and categories
- src/components/* — UI components (form, list, chart, categories manager)
- src/pages/Dashboard.js — main page
- src/App.js — app entry
